# Этап 6. Замеры и релиз

> Читать перед началом: [критерии приёмки](../product/overview.md) · [библиотеки и лицензии](../design/libraries.md) · [проверка](../design/qa.md)

**Цель:** подтвердить экономию энергии и памяти и выпустить установочный APK.

- [ ] 6.1 Замер памяти (Android Studio Profiler и `adb shell dumpsys meminfo <package>`): простой, стрим ответа, поиск файлов. Значения записаны в `docs/measurements.md`.
- [ ] 6.2 Замер батареи: `adb shell dumpsys batterystats --reset`, час простоя с приложением в фоне, затем `dumpsys batterystats`; приложение не в топе потребителей.
- [x] 6.3 Проверено отсутствие фоновой работы: нет сервисов, `JobScheduler`, `AlarmManager` (кроме будильника пользователя через Часы). Проверено по коду и манифесту, см. [measurements.md](../measurements.md); ревью Claude пройдено, таблицу компонентов сверил с итоговым манифестом.
- [ ] 6.4 Release-подпись: keystore хранится вне репозитория, резервная копия сделана.
- [ ] 6.5 Версия `0.1.0`, подписанный APK, установка на «чистый» телефон.
- [ ] 6.6 `docs/INSTALL.md` на русском: как скачать, установить (разрешение на неизвестные источники), войти, что умеет, что не умеет. Ссылка на него из `docs/README.md`. Черновик готов, ждёт проверки установкой по инструкции.
- [ ] 6.7 Пройдены все критерии приёмки из [product/overview.md](../product/overview.md) (раздел «Критерии приёмки»).
- [ ] 6.8 Тексты лицензий шрифтов (OFL), иконок (Apache 2.0) и библиотек доступны на экране «О приложении».

**Что должно быть по итогу:** APK, который человек без опыта ставит и использует без дополнительных программ; `docs/measurements.md` с цифрами; список известных ограничений.

**Как проверить:** установка APK на чистом телефоне без Android Studio, вход, три сценария из этапа 4, цифры замеров записаны.

**Ворота:** MVP принят по ТЗ.
