- `docs/backend-notes.md` с проверенными значениями;

**Как проверить:**
- Скрипт выполняется с нуля одной командой и печатает финальный ответ модели.
- `grep -ri "access_token\|refresh_token\|Bearer " spike/ docs/` не находит реальных значений.
- Значения из `backend-notes.md` совпадают с тем, что реально ушло в запросах скрипта.

**Ворота:** решение записано. При NO-GO: правим [требования](../product/requirements.md) (раздел «Авторизация»: основной `ApiKeyAuth`) и идём дальше, проект не останавливается.
