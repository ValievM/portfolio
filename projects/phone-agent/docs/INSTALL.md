# Установка и первый вход

Инструкция для человека без опыта программирования: как поставить приложение на телефон и войти в него. Компьютер, ADB и Termux не нужны.

## Что это

«Телефонный агент» — приложение-чат с моделью OpenAI, которая умеет поставить будильник, показать уведомление и найти файл на телефоне. Всё, что имеет последствия (будильник, открытие ссылки или файла), приложение сначала показывает и спрашивает разрешения.

## Что нужно

- Телефон с Android 8.0 или новее (минимальная версия задана в приложении).
- Интернет.
- Аккаунт ChatGPT (подписка) или API-ключ OpenAI — хотя бы один из двух.

Компьютер, ADB, Termux — не нужны.

## Установка APK

Файл приложения (APK) версии 0.1.0: `<ССЫЛКА НА APK>`. Способ раздачи ещё не выбран — когда появится, ссылка заработает.

Установить файл не из магазина приложений:

1. Скачайте APK на телефон и откройте его.
2. Android спросит, разрешить ли этому источнику («браузеру», «проводнику») устанавливать приложения. Разрешите — это ожидаемый шаг для приложений не из магазина; пункт меню называется по-разному и зависит от производителя и версии Android («Установка неизвестных приложений», «Неизвестные источники»).
3. Если Android покажет предупреждение, что приложение из неизвестного источника может быть небезопасным, — это то же самое ожидаемое сообщение для APK не из магазина. Решение ставить — за вами.

## Первый вход

Приложение предложит выбрать способ входа («Выберите способ входа»):

1. **«Войти через OpenAI»** — откроется браузер, вы входите в аккаунт ChatGPT, и браузер вернёт вас в приложение. На время входа приложение слушает ответ на порту 1455 на самом телефоне — ничего настраивать не нужно.
2. **«Войти через код устройства»** — если первый способ не сработал. Код действует 15 минут. В настройках безопасности ChatGPT должна быть включена авторизация по коду устройства (подсказка в приложении: «Код действует 15 минут. В настройках безопасности ChatGPT должна быть включена авторизация по коду устройства.»).
3. **«Использовать API-ключ»** — введите ключ OpenAI (начинается с `sk-…`). Ключ проверяется запросом списка моделей и сохраняется зашифрованным. **Работа этого способа на живом бэкенде не проверена.**

Если порт входа занят другим приложением, появится сообщение «Порт входа занят. Используйте код устройства или API-ключ.» — тогда используйте второй или третий способ.

## Что умеет

- **Будильник.** Скажите: «Поставь будильник на 07:30». Приложение покажет подтверждение и после вашего «Разрешить» отправит запрос в приложение «Часы». Оно не может проверить, что будильник появился, — проверьте сами в «Часах».
- **Уведомление.** Скажите: «Покажи уведомление «Сделать перерыв»». При первом использовании Android спросит разрешение на уведомления.
- **Поиск файла по имени** среди файлов, доступных приложению. Скажите: «Найди PDF в выбранной папке». При первом использовании Android спросит доступ к медиафайлам; результат может быть неполным из-за ограничений Android.
- **Поиск в выбранной папке.** «Настройки → Папка для поиска файлов → Выбрать папку» — после этого поиск ограничен этой папкой и её вложенными папками.

Содержимое файлов не читается и в модель не отправляется: передаются только имя, путь, размер, дата и тип файла.

## Ссылки и файлы из ответов

- Ссылка из ответа открывается только после подтверждения, где показан настоящий сайт; открываются только `https`-ссылки, остальные блокируются.
- Файл из результата поиска открывается тоже после подтверждения («Открыть файл?»).

## Чего не умеет

Управлять другими приложениями, читать содержимое файлов, отправлять SMS, звонить, читать контакты, работать в фоне, ставить напоминания по расписанию, вести несколько чатов, слушать голосовые команды.

## Настройки

В «Настройках»: способ входа и статус аккаунта, выбор модели («По умолчанию (gpt-5.6-luna)» или другая из списка), тема (системная/светлая/тёмная), цвета системы из обоев (Android 12 и новее), папка для поиска файлов, «Очистить историю», «Выйти».

## Данные и выход

На устройстве хранятся: ключи и токены (зашифрованы ключом из Android Keystore), история чата (в базе приложения), настройки. Резервное копирование в облако Google выключено.

- «Выйти» стирает ключи и токены. История чата остаётся — **это текущее поведение, решение о его изменении ещё не принято**.
- «Очистить историю» в настройках удаляет сохранённые сообщения с устройства.

## Если что-то не работает

- **Нет сети:** появится баннер «Нет сети. Проверьте подключение и повторите запрос» с кнопкой «Повторить».
- **Сессия завершилась:** «Сессия завершилась. Войдите снова» — нажмите «Войти заново».
- **Порт входа занят:** «Порт входа занят. Используйте код устройства или API-ключ.»
- **Ключ отклонён:** «API-ключ отклонён. Проверьте его и попробуйте снова.»
- **Разрешение отозвано:** поиск файлов перестанет находить файлы. Верните разрешение в настройках телефона: «Приложения → Телефонный агент → Разрешения» (название пунктов зависит от производителя).
- **Не открывается файл или ссылка:** «Не удалось открыть файл. Проверьте доступ или установите приложение для этого типа файла.»

## Известные ограничения

- Тексты и поведение подтверждены тестами, но установка по этой инструкции на живом телефоне ещё не проверена.
- Способ входа по API-ключу на живом бэкенде не проверен.
- Способ раздачи APK не выбран, ссылка на файл — заглушка.
- Поиск файлов может быть неполным: часть загрузок других приложений недоступна без выбора папки.
- Замеров батареи и памяти пока нет.
