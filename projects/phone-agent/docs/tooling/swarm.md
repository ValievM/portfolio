# Команда: GPT-1, GPT-2, GPT-3, Claude и владелец

> См. также: [tracker](tracker.md) · [AGENTS.md](../../AGENTS.md) · [OWNER-TASKS.md](../../OWNER-TASKS.md)

Три GPT работают роем: сами разбирают свою очередь из GitHub Issues, запускают субагентов и проверяют друг друга по кольцу. **Claude оркестрирует и решает все вопросы реализации** (да/нет по дизайну кода, тестам, порядку задач, слияниям). **Владелец только проверяет результат**: телефон, вид приложения, свои ключи и аккаунт; его о реализации не спрашивают. GLM выведен из работы (он единственный работал без роя, и его отчёты приходилось пересылать вручную).

## Кто за что отвечает (зоны кода)
| Участник | Метка | Зона | Что делает |
|---|---|---|---|
| **GPT-1** | `who:gpt1` | логика: `:core:domain`, `:tools`, `:data:llm`, `:data:auth` | цикл агента, инструменты, протокол, состояние хода |
| **GPT-2** | `who:gpt2` | интерфейс: `:app`, экраны, дизайн-система | экраны, карточки, шторки, вид «Стыка» |
| **GPT-3** | `who:gpt3` | тесты, инфраструктура, документы | контрактные тесты, правила `ArchitectureTest`, доки, мелкий техдолг |
| **Claude** | `who:claude` | оркестрация, интеграция, релиз | задачи, ответы на вопросы, финальное ревью, слияния, CI, релиз |
| **Владелец** | `who:owner` | результат | проверка на телефоне, дизайн «нравится», ключ подписи, вход в аккаунт |

Зоны нужны, чтобы меньше конфликтовать при слиянии: задача из чужой зоны допустима, но правится минимально. Пересечения решает Claude при слиянии.

## Кольцо проверки
| Автор | Проверяет | Потом |
|---|---|---|
| GPT-1 | GPT-2 | Claude |
| GPT-2 | GPT-3 | Claude |
| GPT-3 | GPT-1 | Claude |

Записки («Записка: …») и задачи с пометкой «проверяет Claude» сразу идут к Claude.

## Схема меток
| Шаг | Кто | Метки после шага |
|---|---|---|
| Задача заведена и готова | Claude | `who:gptN` + `status:ready` |
| Захват и работа (субагенты в своих worktree) | GPT-N | `status:doing` |
| Сдача на проверку следующему по кольцу | GPT-N | `who:gptM` + `status:review` |
| Проверка в отдельном worktree | GPT-M | OK: `who:claude` + `status:review`; замечания: автору + `status:doing` |
| Ревью, слияние, закрытие | Claude | issue закрыт |
| Вопрос или блокировка | GPT | `who:claude` + `status:blocked` (Claude отвечает сам) |

## Границы
- GPT меняет только метки `who:`, `status:` и пишет комментарии в issues своей очереди и своих проверок; комментарии начинаются с `[GPT-1]`, `[GPT-2]` или `[GPT-3]` (действия идут от аккаунта владельца).
- Закрывать issues, вливать ветки, пушить в `origin`, создавать и удалять issues и метки может только Claude.
- Gradle: не больше двух запусков одновременно, только через `~/.gradle-agents/gw <кто> <задачи>` (свои папка данных и слот; кэш зависимостей общий, только чтение). Скрипт лежит вне репозитория.
- Субагентов не больше 2 у каждого GPT (вместе не больше 5); сначала задачи с меткой `mvp`.
- Владельцу вопросы по реализации не задаются никогда. Ему выносятся только: проверка результата, действия на его телефоне, секреты и ключи, вход в аккаунт, траты.
