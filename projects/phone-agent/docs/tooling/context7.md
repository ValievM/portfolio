# Context7 (только в этом проекте)

> См. также: [stages/a-environment.md](../stages/a-environment.md) (история установки) · [architecture/testing.md](../architecture/testing.md) · [README.md](../README.md)

## Область действия
Context7 выключен глобально (`enabled = false` в `~/.codex/config.toml`, чтобы не грузить его зря в остальных проектах) и включён обратно только для phone-agent через project-scoped `.codex/config.toml` в корне репозитория (Codex CLI читает его для доверенных проектов: `trust_level = "trusted"` в `[projects."<путь>"]` глобального конфига). Файл в git, поэтому применяется одинаково во всех worktree. Для нового worktree вне уже доверенных путей Codex либо запросит доверие, либо project-local конфиг тихо не подхватится: тогда работай без Context7.
В Claude Code project-scoped Codex-конфиг не участвует.

## Context7: актуальная документация библиотек
Не полагайся на память для API библиотек. Перед кодом, который использует Compose, AndroidX (DataStore, Room, Keystore), OkHttp, kotlinx.serialization, kotlinx.coroutines, Navigation 3, markdown-библиотеку:
1. `resolve-library-id` (библиотека + твой вопрос) → выбери подходящий ID.
2. `query-docs` (ID + конкретный вопрос) → используй ответ.

Правила:
- Указывай версию из `gradle/libs.versions.toml`.
- Не больше 2-3 вызовов на один вопрос, большие выдержки не вставляй в ответ.
- **В запросах в Context7 нет токенов, ключей, данных пользователя и чужого кода.** Запросы уходят на внешний сервис.
- Context7 только для библиотек. Контракт входа и бэкенда OpenAI берётся из `docs/backend-notes.md` и исходников `openai/codex`, а не из Context7 и не из памяти.
- Если имя инструмента отличается от `query-docs`, смотри актуальный список инструментов.

## История: Serena удалена
Serena (навигация по символам) использовалась на этапах A-5 и была удалена 2026-09-26 по решению владельца: инструмент, его данные (`~/.serena`, около 2,6 ГБ), процессы и конфиги сняты. Навигация по коду теперь обычная: `rg`/`grep`. Упоминания Serena в ADR 0001 и в файлах этапов A и 1 остались как история.
