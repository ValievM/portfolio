# Фирменный стиль «Стык»

> Источник: бренд-пакет от 24.09.2026 (выбрано направление «Стык»). Значения цвета: [brand/joint-tokens.json](brand/joint-tokens.json). Решение: [ADR 0006](../adr/0006-brand-joint.md).

## Идея
Столярный стык: две подготовленные детали, которые работают вместе. Зазор остаётся видимым: просьба пользователя и выполнение не сливаются. Приложение остаётся «Телефонный агент» (имя-кандидат «Ладви» не проверено юридически, не используем).

## Характер
- Собранные: показываем параметры до действия, интерфейс не превращаем в панель приборов.
- Тёплые: пишем по-человечески, не фамильярничаем.
- Предсказуемые: обозначаем фазу, не обещаем неподтверждённый результат.
- Сдержанные: один акцент, ошибки не маскируем улыбкой.
- Уважительные: отказ завершает действие, не уговариваем разрешить.
Позиционирование: помощник, с которым действия на телефоне остаются под вашим контролем.

## Знак
Два замкнутых многоугольника на сетке 64, между ними виден зазор:
```
левый:  M10 14H26V24H20V42H32V52H10Z
правый: M38 12H54V50H44V32H32V22H38Z
```
Цвет: `#753E4A` на светлом, `#EDB4BF` на тёмном, монохром для слоя тематической иконки Android 13+. Адаптивная иконка: слои 108x108 dp, содержимое внутри круга 66 dp (масштаб 1,1, сдвиг 18,8 dp), фон `#753E4A`, передний план `#FFFFFF`. Не добавлять фон, тени и эффекты к знаку.

## Геометрия и текст (внедрено)
Токены в `ui/designsystem/theme`: формы `AppTheme.shapeTokens` (пузырь пользователя 20dp с «хвостом» 4dp, карточка 16dp, верх шторки 28dp, кнопка 16dp, композер 24dp; радиусы не растут при крупном шрифте), шкала текста `AppTypography` (Inter, заголовки и кнопки weight 600, трекинг 0), код `AppCodeTextStyle` (JetBrains Mono 14/22, лигатуры выключены), время `AppTimeTextStyle` (24/30, табличные цифры), отступ `spacing.compact` = 12dp.

## Статусы инструмента
Иконка + слова на паре «контейнер / on-цвет», цвет не единственный носитель смысла:
| Статус | Роль | Иконка, текст |
|---|---|---|
| Ждёт решения | `warningContainer` | часы, «Нужно подтверждение» |
| Выполняется | `primaryContainer` | незамкнутое кольцо, «Выполняется» |
| Готово | `successContainer` | галочка, точный результат |
| Ошибка | `errorContainer` | «!» в круге, причина |
| Отклонено, прервано | без заливки, `onSurfaceVariant` | перечёркнутый круг, квадрат; это решение пользователя, не ошибка |

## Движение и адаптивность
- Смена статуса: перекрёстное затухание 120 мс; баннер ошибки: появление по прозрачности 160 мс, без тряски; раскрытие карточки и поворот стрелки: 250 мс (`AppMotion`); смена темы: плавный переход цветов 250 мс, без пересоздания экранов.
- «Готовлю ответ»: знак 24dp из двух деталей, каждая отходит на 1dp наружу и назад за 1200 мс; при «Убрать анимации» (масштаб 0) детали неподвижны.
- Читаемая колонка не шире 640dp по центру (`Modifier.contentColumn()`), поля 20dp (16dp уже 360dp), нижний край и клавиатуру обрабатывает композер. Вход на широком низком экране (ландшафт, планшет) идёт двумя колонками: слева знак и пояснение, справа кнопки. Проверено на 320dp, обычном телефоне, планшете и в ландшафте при шрифте до 200%: пара кнопок сама встаёт столбиком, список в шторке прокручивается, кнопки закреплены.

## Тон текстов (образцы)
- Приветствие: «Здравствуйте. Что сделать на телефоне?»
- Подтверждение: «Подтвердите действие. Оно будет выполнено на этом телефоне.»
- Нет сети: «Нет сети. Проверьте подключение и повторите запрос.»
- Отказ: «Отклонено. Действие не запущено.»
- Остановка: «Ответ остановлен. Уже выполненные действия не отменены.»
Правила: без восклицаний в системных сообщениях, называть конкретный результат, отказ пользователя не оспариваем.
