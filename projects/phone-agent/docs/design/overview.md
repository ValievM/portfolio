## Что решено (кратко)

| Тема | Решение |
|---|---|
| Дизайн-система | Material 3 (стабильная линия 1.4.x) + свои токены. Не Expressive: он в альфе (1.5.0-alpha), вернёмся, когда станет стабильным |
| Цвет | Фирменная палитра «Стык» по умолчанию ([brand.md](brand.md)); цвета системы (Android 12+) отдельным переключателем, выключены по умолчанию |
| Шрифты | Вшитые variable-шрифты: Inter (интерфейс) + JetBrains Mono (код, аргументы); кириллица проверена |
| Иконки | Material Symbols Rounded, импорт нужных (~20) как vector drawable, без библиотеки иконок |
| Навигация | Navigation 3 (стабильная), predictive back из коробки |
| Markdown в ответах | `multiplatform-markdown-renderer` (`-m3`, `-code`), потоковый режим, **картинки выключены** |
| Подтверждение действий | Модальная шторка (`ModalBottomSheet`), не диалог и не карточка в ленте |
| Проверка вёрстки | превью на каждое состояние + `compose-rules` + скриншот-тесты (Roborazzi) для ключевых компонентов |
| Дизайн-процесс | «Дизайн в коде»: токены и превью — источник истины. Figma для MVP не нужна |

## Принципы дизайна

1. **Спокойный инструмент.** Контент важнее украшений: минимум цвета, теней и анимаций.
2. **Действия видны.** Пользователь всегда видит, какие инструменты приложение выполняет или собирается выполнить.
3. **Контроль у пользователя.** «Стоп» и «Отклонить» всегда под пальцем, ничего необратимого без подтверждения.
4. **Native first.** Соглашения Android (Material 3, dynamic color, edge-to-edge, predictive back) вместо своего UI-кита.
5. **Один акцент.** Один основной цвет. Статусные цвета — смысл, а не украшение, и никогда не единственный признак (рядом иконка и текст).
6. **Доступность не опция.** Крупный шрифт, TalkBack, контраст проверяются как функциональность.
7. **Экономия энергии — тоже дизайн.** Никаких бесконечных анимаций и лишних перерисовок.
