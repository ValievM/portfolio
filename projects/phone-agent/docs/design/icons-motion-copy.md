# Иконки, движение, тексты интерфейса

> См. также: [цвет и шрифты](style.md) · [компоненты](components.md)

## Иконки
- Набор: **Material Symbols Rounded**, вес 400, оптический размер 24. Контурные по умолчанию, залитые (fill) для активных и выбранных состояний.
- Размеры: 24dp обычные, 20dp в плотных местах (статус в карточке).
- **Без библиотеки иконок.** Нужных иконок около 20, поэтому берём SVG с Google Fonts Icons (лицензия Apache 2.0) и импортируем в Android Studio: Vector Asset → Local file. Результат: `res/drawable/ic_<имя>.xml`. Иконки Symbols в Vector Asset Studio пока не встроены, поэтому скачиваем вручную (есть плагин-импортёр, но он необязателен).
- Про `material-icons-extended`: сторонние источники пишут, что он устарел; на официальной странице релизов я этого не нашёл. На наше решение это не влияет: библиотека тяжёлая, а иконок нужно мало.
- Обращаемся через один объект `AppIcons` (карта имя → drawable), а не по разбросанным `R.drawable.*`.
- Стартовый набор: `send`, `stop`, `settings`, `close`, `check_circle`, `error`, `warning`, `block`, `alarm`, `notifications`, `folder_open`, `search`, `expand_more`, `content_copy`, `arrow_downward`, `logout`, `key`, `open_in_new`, `hourglass_empty`, `wifi_off`.
- Иконка-кнопка всегда с `contentDescription` (из строк) и областью нажатия 48dp. Чисто декоративные иконки: `contentDescription = null`.
- Иконка приложения: adaptive + monochrome (тематическая иконка Android 13+). Заставка: `core-splashscreen`. Заглушки на этапе 1, финальные позже.
- Альтернативные наборы (Lucide, Phosphor) красивы, но чужды Material 3 и добавили бы зависимость: не берём.

## Движение
- Анимируем только смысл: появление сообщения, раскрытие карточки, шторка, превращение «отправить ↔ стоп», чип «↓ к новым».
- Не анимируем: посимвольный вывод текста (текст просто растёт), декор, бесконечные циклы (кроме короткого индикатора ожидания).
- Токены: `short = 150 мс`, `medium = 250 мс`, `long = 400 мс`; изменения размеров через `spring` (умеренное демпфирование), смена содержимого через fade.
- Системная настройка «Убрать анимации» уважается (Compose учитывает шкалу длительности аниматоров).
- Индикатор ожидания до первого токена: три точки или маленький `CircularProgressIndicator`, исчезает с появлением текста.

## Тактильный отклик
Лёгкий отклик на отправку, «подтверждающий» на «Разрешить», «отклоняющий» на «Отклонить». На стриминг и прочее отклика нет. Конкретные типы `HapticFeedbackType` уточняем через Context7 **[проверить, этап 4]**.

## Тексты интерфейса (микрокопирайтинг)
- Русский, безличные формулировки без «ты/вы» где можно: «Войти через OpenAI», «Разрешить действие?».
- Кнопки: глаголы («Разрешить», «Отклонить», «Остановить», «Повторить»).
- Ошибки: что случилось + что делать («Нет сети. Проверьте подключение и повторите»). Без «Упс», эмодзи и восклицаний.
- Все строки в `strings.xml`, формат-аргументы вместо склейки, `plurals` для чисел. MVP только на русском, но английский добавляется без правки кода.
