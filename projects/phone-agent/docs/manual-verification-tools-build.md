# Ручная проверка: инструменты, вход, сборка, CI

Продолжение [manual-verification.md](manual-verification.md): те же правила (`[x]` ставит **только пользователь** после личной проверки на своём телефоне, агент пункты не отмечает; формат строки и порядок проверки описаны там). Здесь пункты про инструменты, настройки, вход, release-сборку, CI и логи.

## Не проверено пользователем лично

- [ ] `search_files` / `find_files` — поиск находит нужный файл по подстроке имени; файл вне
  разрешённой области (не выбранная SAF-папка, недоступная MediaStore-коллекция) не находится;
  содержимое файла нигде не подтягивается в модель, только метаданные (`tools/files/`).
- [ ] `notify` — уведомление реально появляется с нужным текстом; на API 33+ отказ в
  `POST_NOTIFICATIONS` даёт понятное сообщение, а не тихий провал (этап 4.6).
- [ ] Открытие найденного файла через `ACTION_VIEW` из карточки `FilesFound` — открывается в
  дефолтном приложении, а если такого нет — показывается chooser, а не падение.
- [ ] Экран настроек (`ui/settings/`) — выбор модели реально меняет модель в следующем запросе;
  выход стирает токены; выбор SAF-папки переживает перезапуск, а `find_files` ищет только в
  выбранном дереве; очистка истории сразу обновляет открытый чат и отменяет активный ход без
  восстановления очищенной истории.
- [ ] Обновление токена без сети (`fix/session-race-and-transient`): когда токен уже просрочен и включён режим полёта, чат показывает «нет сети» с «Повторить», а не «сессия истекла»; после включения сети повтор работает без нового входа. То же, если сервер ответил 401, а обновить токен не удалось из-за сети (`fix/refresh-after-unauthorized-transient`, ловится редко: токен должен устареть на сервере раньше срока): «нет сети», не «сессия истекла». Гонку «выход во время обновления» руками воспроизвести трудно, она покрыта тестами.
- [ ] Design QA на телефоне ([design/qa.md](design/qa.md), чек-лист): светлая/тёмная темы, шрифт
  1.0/1.3/2.0, узкий экран и ландшафт, клавиатура не перекрывает композер и последнее сообщение,
  порядок чтения TalkBack, «Убрать анимации». Скриншот-тесты покрывают только вид компонентов,
  не поведение системы; утверждение дизайна → запись эталонов (этап 5.8).
- [ ] Release APK (этап 5.6): release APK запускается, вход работает, markdown рисуется,
  история восстанавливается (сборка с R8-минификацией, подписана debug-ключом — только для
  этой проверки, настоящая подпись на этапе 6).
- [ ] Логи на телефоне (этап 5.5, [log-audit.md](log-audit.md)): после диалога с поиском файла, будильником и
  ошибкой сети `adb logcat` и файл `no_backup/app.log` не содержат текста твоих сообщений, ответов модели,
  имён файлов и токенов.
- [ ] Первый запрос разрешения не обрывается по таймауту (`fix/tool-pipeline-hardening`): сбрось разрешение приложения на уведомления или файлы (Настройки → Приложения → phone-agent → Разрешения), попроси «отправь уведомление» или «найди файл X» и **подожди больше 5 секунд**, прежде чем нажать «Разрешить»: инструмент должен отработать, а не вернуть «timed out after 5000ms». Отказ в разрешении даёт понятное сообщение, а не зависание.
