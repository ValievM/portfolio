# ADR 0001: базовые решения проекта

> См. также: [README.md](../README.md) · [architecture/decisions.md](../architecture/decisions.md) · [design/qa.md](../design/qa.md)

**Статус:** принято 21.09.2026. Владелец может пересмотреть любое решение новым ADR.

## Решения
- Нативное Android-приложение на Kotlin + Compose. Разработка по TDD, агент работает по техническая документация.
- Архитектура: гексагональное ядро `:core:domain` (чистый Kotlin), 5 модулей (`:app`, `:core:domain`, `:data:llm`, `:data:auth`, `:tools`), рост модулей по триггерам. Подробности: [architecture/overview.md](../architecture/overview.md).
- Инструменты как плагины с общим конвейером (`ToolPipeline`); карточка и подтверждение строятся из `Tool.describe`, а не из текста модели.
- Вход: подписка через PKCE + приёмник на `127.0.0.1:1455`, запасной device code, **обязательный** запасной `ApiKeyAuth`. Формат бэкенда изолирован в `:data:llm`.
- Дизайн: Material 3 стабильный (Expressive не берём, пока альфа), динамические цвета, Navigation 3, вшитые шрифты, иконки Material Symbols как vector drawable, markdown без загрузки картинок, подтверждение в шторке. Подробности: [design/overview.md](../design/overview.md).
- Документация: модульная, роутер в `docs/README.md`, техническая документация до 8 КБ, проверка `python3 scripts/check_docs.py`.

Альтернативы и причины: [architecture/decisions.md](../architecture/decisions.md), [design/qa.md](../design/qa.md).

## Что проверено при утверждении
- Ссылки, якоря, «сироты», размеры, структура (code fences, таблицы, один H1): скрипт `scripts/check_docs.py`, результат OK.
- Целостность после разбиения монолита на модули: из 872 содержательных строк старых документов 814 совпали дословно; остальные 58 — сознательно изменённые ссылки и два удалённых дубля (набросок схемы и список этапов в старом ТЗ, они покрыты `architecture/overview.md` и `stages/`).
- Сквозная сверка терминов: `ModelGateway`/`ResponsesGateway`, `CredentialsProvider`/`SessionManager`, `BackendProfile`/`AuthConfig`, `Tool.describe`/`CallDescription`, «шторка подтверждения». Найденные расхождения исправлены.
- Добавлено правило про порт 1455: чужое приложение может занять порт, защита — PKCE + `state` + device code.

## Что остаётся непроверенным (закрывается на этапах)
| Этап | Что проверяем |
|---|---|
| A | Codex загружает техническая документация и следует роутеру; Serena и Context7 подключаются и работают у владельца |
| 0 | Контракт входа и бэкенда подписки: заголовки, тело запроса, события SSE, обновление токена, нужен ли слот `Opaque`; решение GO/NO-GO |
| 1 | Актуальные версии библиотек; Konsist-правила, включая запрет литералов в `Text("…")`; кириллица в выбранном шрифте; strong skipping; Kover (по желанию) |
| 3 | Порядок обхода TalkBack при `reverseLayout`; типы haptic-отклика (этап 4) |
| 5 | Roborazzi, скриншот-тесты |

## Последствия
- Код пишем только по этим документам. Отступление: вопрос владельцу, затем новый ADR.
- Документы содержат допущения (пометки `[проверить]`). До закрытия на этапе они считаются гипотезами, а не фактами.
- Главный внешний риск: бэкенд подписки закрытый и может измениться. Страховка заложена (`ApiKeyAuth`, изоляция в `:data:llm`), но полностью риск не убирается.
