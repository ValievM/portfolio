# ADR 0002: основной вход через подписку (GO)

> См. также: [backend-notes.md](../backend-notes.md) · [0001-baseline.md](0001-baseline.md) · [product/requirements.md](../product/requirements.md)

**Статус:** принято 22.09.2026 по итогам этапа 0.

## Контекст
Главный риск проекта: приложение работает на подписке ChatGPT через закрытый бэкенд, правила которого известны только из исходников Codex и неофициальных источников.

## Решение
Основной способ входа: подписка (браузерный PKCE на `127.0.0.1:1455`, запасной device code). `ApiKeyAuth` остаётся обязательным запасным способом. Константы входа и бэкенда только в `AuthConfig` и `BackendProfile`.

## Основание
Живой запуск `spike/probe.py`: вход, обновление токена (refresh-токен ротируется), список моделей, запрос с вызовом инструмента и ответ прошли на аккаунте Plus. Подробности и статусы значений: [backend-notes.md](../backend-notes.md).

## Последствия
- Refresh-токен обновляется атомарно и под мьютексом (он ротируется).
- Парсер SSE не опирается на `Content-Type`.
- Значение `originator` и остальные заголовки лежат в `BackendProfile` и могут меняться без правки кода.
- Перед релизом проверку повторить: бэкенд закрытый.
- Не проверено: приёмник на Android, будильник, device code, лимиты (см. backend-notes).
