# ADR 0006: фирменный стиль «Стык»

Статус: принято 2026-09-25 (выбор владельца продукта).

## Контекст
Цвета брались из обоев телефона (динамические цвета), знак и иконка были заглушками, поэтому приложение ничем не отличалось от других. Нужен узнаваемый стиль без риска для читаемости.

## Решение
1. Направление «Стык» из бренд-пакета (вино и тёплая «бумага», знак из двух деталей): [brand.md](../design/brand.md).
2. Источник значений: `docs/design/brand/joint-tokens.json`; Kotlin-схемы `BrandColorSchemes.kt` генерируются из него, `BrandThemeTokensTest` проверяет совпадение и контраст.
3. «Цвета системы» остаются настройкой, но выключены по умолчанию. Ключ хранилища новый (`use_system_colors`): старый `use_dynamic_colors` по умолчанию был `true` и записывался при каждом сохранении настроек, повторное использование оставило бы у существующих установок цвета обоев.
4. Тема «Как в системе / Светлая / Тёмная» настраивается и применяется сразу: в порт `SettingsRepository` добавлен `observe()` (по умолчанию выдаёт значение один раз), `MainActivity` держит заставку, пока сохранённая тема не прочитана, чтобы не мигать чужой темой.
5. Имя приложения не меняем.

6. Внедрение по контракту `THEME-CONTRACT` (в архиве бренда): при расхождении с брендбуком побеждает контракт. Сообщение пользователя на `secondaryContainer` (в книге `primaryContainer`), поле ввода `surfaceContainerHigh` на панели `surfaceContainerLow`, рамка и фокус поля `outline`.
7. Корень приложения: `ThemeViewModel` (`Loading`, `Ready`, `Unavailable(lastKnown)`), ошибка чтения не превращается в настройки по умолчанию и ничего не пишет, «Повторить» только по нажатию. Пока настройки не прочитаны или чтение упало, `SettingsViewModel` ничего не сохраняет: иначе тема затёрла бы модель и папку значениями по умолчанию.
8. Тексты по варианту A из брендбука (F5): вход, пустой чат, статусы, ошибки сети/сессии/таймаута/лимита. Имя «OpenAI» на кнопке входа оставлено: это факт, а не название бренда.
9. Кнопки-обёртки (`PrimaryButton` и др.), `ConfirmationSheet` без половинного состояния, `android:enableOnBackInvokedCallback` (жест «назад» с анимацией) и плавная смена темы приняты как часть внедрения.

## Последствия
- Существующие установки получат фирменные цвета; «цвета системы» надо включить вручную.
- Любое изменение палитры делается в JSON и перегенерируется, ручные правки `BrandColorSchemes.kt` ломают тест.
- Иконка, знак на входе и оставшиеся компоненты переводятся на новую систему отдельными ветками; эталоны скриншотов записываются после утверждения на телефоне.
